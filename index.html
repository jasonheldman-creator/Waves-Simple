❌ Deployment Not Configured

The WAVES Intelligence™ site is not yet configured for deployment. You're seeing this page because the Vercel Root Directory setting is missing.

📍 Site Location

The Next.js application is located in the /site subdirectory of this repository, not at the root.

✅ How to Fix This

Configure the Root Directory in your Vercel Dashboard:

  1. Open Vercel Dashboard
  2. Select your project: Waves-Simple
  3. Go to Settings → General
  4. Scroll to Root Directory
  5. Click Edit
  6. Enter: site
  7. Click Save
  8. Go to Deployments tab
  9. Click Redeploy on the latest deployment
📚 Documentation

For complete setup instructions, see:

  • DEPLOY_TO_VERCEL.md - Quick start guide
  • VERCEL_SETUP.md - Complete setup guide
  • VERCEL_CONFIG.md - Configuration reference

💡 Why This Happens: Vercel cannot determine the project root automatically when the Next.js app is in a subdirectory. The Root Directory setting tells Vercel where to find your application code.
